# Production source

The production modules are `core/CORE_Rates.bas` and `modules/PREPAY_Rates.bas` (SMM and CPR conversions), and the data-format primitives of the import: `core/CORE_Csv.bas` (lines and fields), `core/CORE_Parse.bas` (dates, decimals under D17, codes), `core/CORE_Sha256.bas` (pure-VBA SHA-256) and `core/CORE_Import.bas` (validation of one import from the bytes of its three files: E01–E17, W01–W06, exposures, risk-set outcomes, lineage counts, reconciliation totals and control totals) (#42). `core/CORE_Dataset.bas` keeps the accepted dataset of the Excel session (W7), `modules/PREPAY_Dataset.bas` is the import facade, and `workbook/WB_ImportAdapter.bas` is the first workbook adapter, with the entry point `WB_Import`: it reads the three user-selected files read-only (W10) and writes the import areas (#42). None has been compiled or run in Excel. Supported signatures are in [`docs/PUBLIC_API.txt`](../docs/PUBLIC_API.txt). Follow [the architecture](../docs/REPOSITORY_STRUCTURE.md): independent core, supported facade and thin Excel adapters. Add source only against an agreed contract and issue. Do not copy NMD calculation modules into this project.
