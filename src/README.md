# Production source

The production modules are `core/CORE_Rates.bas` and `modules/PREPAY_Rates.bas` (SMM and CPR conversions), and the data-format primitives of the planned import: `core/CORE_Csv.bas` (lines and fields), `core/CORE_Parse.bas` (dates, decimals under D17, codes), `core/CORE_Sha256.bas` (pure-VBA SHA-256) and `core/CORE_Import.bas` (validation of one import from the bytes of its three files: E01–E16, W01–W06, exposures and risk-set outcomes) (#42). None has been compiled or run in Excel, and there is no `workbook/` adapter yet. Supported signatures are in [`docs/PUBLIC_API.txt`](../docs/PUBLIC_API.txt). Follow [the architecture](../docs/REPOSITORY_STRUCTURE.md): independent core, supported facade and thin Excel adapters. Add source only against an agreed contract and issue. Do not copy NMD calculation modules into this project.
