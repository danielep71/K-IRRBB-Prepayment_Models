# Verification

`modules/` holds the VBA test harness (`TEST_Harness`, entry points `TEST_RunAll` and `TEST_RunInjected`) and the rate-conversion tests (`TEST_Rates`), part of the test build only (#42). They have not run in Excel. `fixtures/` holds hand-constructed synthetic inputs, one folder per case and variant; `expected/` holds the expected result of each case with its provenance; `reference/` holds the independent reference reader of the data contract, run by `tools/test_reference_cases.py` through `python tools/check.py` (#41). Future fixtures must be synthetic and include provenance, independent expected values and tolerances. Current tooling tests live in tools/ and run through `python tools/check.py`. The [validation plan](../docs/methodology/VALIDATION_PLAN.md), [case register](../docs/methodology/TEST_CASES.md) and [Excel evidence](../docs/EXCEL_EVIDENCE.md) define numerical and real-Excel evidence (accepted in #15; eleven DATA reference cases now run offline, with no Excel execution); static checks are not that evidence.
